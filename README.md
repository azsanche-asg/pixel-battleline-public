# Pixel Battleline

An offline iPhone arcade strategy game about steering a small army across three lanes.

[Pixel Battleline at Burrito’s Labs](https://burritoslabs.com/catalogue/pixel-battleline/)

## Technology

Swift, SpriteKit, UIKit and AVFoundation.

## Architecture

The game presents lane decisions, formation changes and combat through SpriteKit. A deterministic rules layer resolves movement, gates, encounters and results.

## Product behavior

The shipped game is designed for short runs across three worlds. The App Store listing carries the current compatibility and availability information.
